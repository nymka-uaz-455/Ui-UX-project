# Repository Overview

This repository tracks homework, the individual project, and presentations in one place. This is where the instructor will find verifiable results and submitted versions.

## Structure

| Folder | Contents |
|---|---|
| `homework/` | Homework submissions, one subfolder per assignment (`01/`, `02/`, ...) |
| `presentation/` | Presentation materials, one subfolder per presentation (`01-01/`, ...) with slides and handout |
| `project/` | The individual project: its own README and documentation in `docs/` |
